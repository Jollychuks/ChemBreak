CHEMBREAK COLAB GENERATOR V2 - QUICK START

1. Put the entire ChemBreak_Colab_Generator_v2 folder in your GitHub repo.
2. Open ChemBreak_Colab_Generator_V2.ipynb in Google Colab.
3. Select Runtime > Change runtime type > GPU.
4. In the setup cell, paste your GitHub repository URL.
5. Set PROJECT_SUBDIR to the folder location inside the repo.
6. Run the notebook from top to bottom.
7. The default pilot selects 18 matrix rows across HC1-HC9.
8. It generates 5 candidates per row, for 90 raw candidates.
9. The notebook test uses automatic retries if Qwen violates scenario or JSON rules.
10. Run the optional semantic validator after generation.
11. Review the resulting ACCEPT / REVISE / REJECT counts.
12. Do not run the 6,775-candidate full configuration until the stratified pilot looks good.
13. No paid LLM API key is used.
14. A GitHub token is only needed if you choose to PUSH generated checkpoints back to GitHub.
