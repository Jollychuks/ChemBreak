CHEMBREAK COLAB GENERATOR V3 QUICK START

1. Upload the entire ChemBreak_Colab_Generator_v3 folder to your ChemBreak GitHub repository.
2. Open ChemBreak_Colab_Generator_V3.ipynb in Google Colab.
3. Select Runtime > Change runtime type > GPU.
4. Run the notebook from top to bottom.
5. The notebook clones https://github.com/Jollychuks/ChemBreak.git into /content/chembreak_repo.
6. PROJECT_SUBDIR is already set to ChemBreak_Colab_Generator_v3.
7. The default pilot uses 18 matrix rows across HC1-HC9.
8. It generates 5 candidates per row, for 90 raw candidate tasks.
9. Python, not Qwen, controls scenario assignment.
10. One candidate is generated and saved per model call.
11. Run the optional semantic validator after generation.
12. Review ACCEPT, REVISE, and REJECT results before scaling.
13. Generated CSV files remain in the temporary Colab clone until you push or download them.
14. No paid LLM API key is used.
