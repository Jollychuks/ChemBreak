# Start here — ChemBreak 13

Use the `chembreak13/` folder in this package. Add that folder to the root of your GitHub repository `https://github.com/Jollychuks/ChemBreak.git`, commit, and push to `main`.

Then open `chembreak13/chembreak13_Cloud_Notebook.ipynb` (or the identical copy under `chembreak13/notebooks/`) in Google Cloud Notebook Enterprise and run the cells top to bottom.

The first notebook cell contains the familiar editable values: `PROJECT_ID`, `REPO_URL`, `BRANCH`, `PROJECT_SUBDIR`, `EXPERIMENT_REVISION`, and `LIVE`.

This package does not use any ChemBreak 12 storage, checkpoints, or caches. Runtime storage is `/content/chembreak13_storage`.
