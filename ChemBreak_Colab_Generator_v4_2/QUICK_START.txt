CHEMBREAK V4.2 QUICK START

1. Upload the complete folder:
   ChemBreak_Colab_Generator_v4_2

2. Open:
   ChemBreak_Colab_Generator_V4_2.ipynb

3. Use a GPU runtime.

4. If you previously ran an older ChemBreak notebook in the same Colab
   session, choose Runtime > Restart session first.

5. Run from Cell 1 in order.

6. Cell 1 checks that the kernel has not already imported PyTorch/model
   packages and confirms the NVIDIA GPU with nvidia-smi.

7. Cell 3 runs bootstrap_colab.py:
   - child-process PyTorch probe
   - automatic repair to the official matched CUDA 12.8 trio if required
   - installation of non-PyTorch ChemBreak dependencies
   - complete child-process verification

8. Cell 3B imports the verified stack into the notebook and checks it again.

9. Keep:
   CONFIG_FILE = "run_config_smoke.json"

10. Smoke experiment:
    - 1 matrix row
    - 2 candidate positions
    - 4 generator families
    - 8 generated candidates
    - 32 blind judgments

11. Only after all four models generate and judge successfully, change to:
    CONFIG_FILE = "run_config.json"

12. Full V4.2 pilot:
    - 18 matrix rows
    - 5 candidates per row
    - 4 generator families
    - 360 candidate tasks
    - 1,440 blind judgments

13. For long Colab runs, run one generator or judge family per session.

14. Enable GitHub checkpointing before deleting a runtime if you want the
    generated output preserved automatically.

15. Do not manually install or upgrade torch, torchvision, or torchaudio
    inside the V4.2 notebook. bootstrap_colab.py owns that stack.
