# GitHub upload checklist, V2

Upload the complete `ChemBreak_Adaptive_Jailbreak_v2/` folder to the root of `https://github.com/Jollychuks/ChemBreak`.

Before committing, confirm the folder contains the V2 notebook, `configs/gcp.yaml`, `chembreak/`, `scripts/`, `tests/`, `README.md`, `RUN_MANIFEST.yaml`, `VERSION_2_NOTES.md`, and `.gitignore`.

Do not upload `configs/runtime.yaml`, `outputs/`, Hugging Face caches, the completed harmful task bank, raw transcripts, credentials, or model weights.

The package never pushes to GitHub automatically.
