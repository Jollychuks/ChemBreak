CHEMBREAK V4 QUICK START

1. Upload the complete `ChemBreak_Colab_Generator_v4` folder to your ChemBreak GitHub repository.

2. Open `ChemBreak_Colab_Generator_V4.ipynb` in Google Colab.

3. Select a GPU runtime.

4. Run the dependency-install cell.
   V4 pins Hugging Face Transformers 5.15.0 so separate Colab sessions use the same model-runtime version.

5. Keep `CONFIG_FILE = "run_config_smoke.json"` first.
   The smoke run uses:
   - 1 matrix row
   - 2 candidate positions: one NONE baseline and one scenario-conditioned task
   - 4 generator families
   - 8 generated candidates
   - 32 blind judgments

6. If a Hugging Face model repository requires authenticated access, set `USE_HF_TOKEN = True` and enter the token only when Colab asks. Do not store the token in GitHub.

7. After the smoke run succeeds for all four families, change:
   `CONFIG_FILE = "run_config.json"`

8. The full V4 pilot then creates:
   - 18 matrix rows
   - 5 candidates per row
   - 4 generator families
   - 360 generated candidates
   - 4 judges per candidate
   - 1,440 blind judgments

9. Models are loaded sequentially, not simultaneously.

10. For a long run, execute one generator or one judge family per Colab session by changing the family list in the notebook. Resume-safe IDs prevent duplication.

11. Run the comparison aggregation.

12. Create the blinded human-review sample.

13. Fill the eight human score columns before opening the hidden generator key.

14. Run the human-calibration analysis.

15. Review:
   - automated all-judge generator ranking
   - automated cross-family generator ranking
   - self-family judge bias
   - pairwise judge agreement
   - human-calibrated judge ranking
   - human-calibrated generator ranking

16. Select the final generator and final primary/secondary judges only after the human calibration.

17. Optional GitHub checkpointing can be enabled in the config. The GitHub token is entered at runtime only.

18. Do not scale to thousands of final ChemBreak tasks until the V4 comparison is reviewed.
